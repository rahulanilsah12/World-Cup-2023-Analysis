# World-Cup-2023-Analysis
**Project Title: ICC Men's Cricket World Cup 2023 Analysis Using Python**

**GitHub Repository:** https://github.com/YOUR-USERNAME/World-Cup-2023-Analysis

### Project Overview

This project focuses on analyzing the ICC Men's Cricket World Cup 2023 using Python to identify meaningful insights into player performances, team statistics, stadium conditions, and match outcomes.

### Key Analysis Areas

- Identification of top run-scorers and best bowlers in individual matches.
- Analysis of stadiums and their batting and bowling conditions.
- Player of the Match award distribution.
- Comparison of player performances across different teams.
- Analysis of match outcomes, including victories by runs and wickets.
- Identification of team-wise and venue-wise performance patterns.

### Tools and Technologies

- Python
- Pandas
- Matplotlib
- Plotly
- MySQL
- Microsoft Excel
- Google Colab

### Key Findings

- Daryl Mitchell was the best scorer in three matches.
- Adam Zampa was the best bowler in five matches.
- Travis Head and Mohammad Shami received three Player of the Match awards each.
- Batsmen and all-rounders were the most frequent Player of the Match winners.
- India won five matches by runs and five by wickets.
- Australia won four matches by runs and five by wickets.

### Project Outcome

The project demonstrates the application of Python-based data analysis and visualization in sports analytics. It provides insights into individual player contributions, team performance, stadium conditions, and match-winning patterns during the 2023 Cricket World Cup.

**Note:** The analysis is based on the project dataset and is intended for educational and analytical purposes.
